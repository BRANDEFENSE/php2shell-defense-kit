# Microsoft Defender Advanced Hunting examples

These files target `DeviceProcessEvents` and `DeviceFileEvents` in Microsoft Defender Advanced Hunting. They are examples for local review, not generated equivalents of every Sigma rule. They have not been executed in a live Defender tenant in this release.

Use the schema available to your tenant/platform. Linux event and file coverage depends on onboarding, sensor capabilities and policy. Direct parent names alone do not prove PHP context. `w3wp.exe` can host other technologies. Renamed/wrapped runtimes can be missed. Tune time windows, names and roots, and baseline legitimate subprocesses/deployments.

No HTTP body/cookie or PHP error telemetry is assumed to be present in these tables.
